    Titre : Brain Maze – Puzzle Néon
Sous-titre : Résous des labyrinthes lumineux !

Description courte :
Guidez la balle néon à travers des labyrinthes palpitants.
Évitez les pièges, utilisez les téléporteurs et battez le chrono !

Description longue :
🧩 Brain Maze est un jeu de puzzle captivant au design néon.

🎮 COMMENT JOUER :
• Glissez votre doigt ou inclinez votre téléphone
• Guidez la balle lumineuse vers l'arrivée
• Évitez les pièges mortels
• Utilisez les téléporteurs à votre avantage
• Terminez avant que le temps ne s'écoule !

⭐ CARACTÉRISTIQUES :
• 10+ niveaux de difficulté croissante
• Design néon époustouflant
• Contrôle par touch ou accéléromètre
• Murs mouvants et téléporteurs
• Système d'étoiles et meilleurs temps
• Effets haptiques immersifs
• Aucune connexion internet requise

🏆 Gagnez 3 étoiles sur chaque niveau !

Catégorie : Jeux > Puzzle
Classification : Tout public (PEGI 3)
